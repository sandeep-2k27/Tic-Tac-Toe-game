# ❌⭕ Tic Tac Toe Game

A classic Tic Tac Toe game built using HTML, CSS, and JavaScript. The game allows two players to compete against each other by taking turns placing their marks on a 3×3 grid. The application automatically detects winners, handles draw situations, and provides a smooth and interactive gaming experience.

---

## 🚀 Features

### 🎮 Gameplay

* Two-Player Mode
* Turn-Based Gameplay
* Interactive Game Board
* Automatic Turn Switching

### 🏆 Game Logic

* Winner Detection
* Draw Detection
* Winning Message Display
* Game Reset Functionality

### ⚡ Functionality

* Real-Time Move Updates
* Instant Result Calculation
* Restart Game Option
* Smooth User Interaction

### 🎨 User Interface

* Clean and Modern Design
* Responsive Layout
* Interactive Buttons
* User-Friendly Experience
